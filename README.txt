SARAHI ALMENAR NAILS STUDIO — PWA

Qué incluye
- App web instalable (PWA) para Android/Chrome y navegadores compatibles.
- Funcionamiento offline después de la primera carga.
- Datos locales en el dispositivo + respaldo JSON/CSV desde Configuración.
- Reservas, clientas, servicios, caja y reportes de la versión original, con el comportamiento existente conservado.

Instalación en Android
1. Publica esta carpeta en un hosting HTTPS.
2. Abre la URL en Chrome.
3. En la app: Más → Instalar app, o usa el menú de Chrome → Instalar aplicación.

Instalación en iPhone/iPad
1. Abre la URL en Safari.
2. Compartir → Añadir a pantalla de inicio.

Importante
- La versión PWA necesita HTTPS para que el navegador permita el service worker e instalación completa.
- Los datos siguen siendo locales: usa “Descargar respaldo completo” con regularidad.
